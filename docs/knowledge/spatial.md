# 空间分布

## 怎么数格子

`detect_cabbage` 返回的 `grid` 把画面**均分**成 n×n 格（默认 4×4），
统计每格有几个框。

归属规则：**按框中心点落在哪格**，不按面积分摊。所以

    sum(grid.counts) == count

恒成立，用户拿总株数一加就能核对。按面积分摊会得到 3.4 株这种数，
反而没法核。代价是一株跨线时归属由中心点决定，边界附近可能有 1 格误差。

坐标轴是**图像**，`[0][0]` 是左上格。不是地块坐标——图是裁出来的。

## 「均匀」用什么量

用 `vmr`（方差 / 均值比，空间点格局里 quadrat count 的标准检验量）：

| vmr | 含义 |
|---|---|
| ≈ 1 | 与随机撒点无法区分 |
| < 1 | 比随机更规则（等距、成行） |
| > 1 | 有聚集（斑块） |

不用变异系数 CV，因为**它会随 n 漂**：同一张图 n=4 时 CV=0.30、n=6 时 0.52，
一套阈值会把"格子变小"误判成"分布变差"。同一张图的 VMR 是 0.35 和 0.47，
结论一致。

实测（30 张验证图，conf=0.25）：

| 粒度 | VMR 范围 | 中位 |
|---|---|---|
| 4×4 | 0.12 ~ 0.51 | 0.31 |
| 6×6 | 0.17 ~ 0.92 | 0.38 |

**没有一张超过 1。** 甘蓝是定植的，株行距本身规整，所以"比随机更规则"
是这批数据的常态，不是异常发现。`pattern=有聚集` 这一档在验证集上
一次都没触发——它是对超出已验证范围的情况报警，不是"看起来不均"的形容词。

`grid.counts` 的极值只看**数值**：最密格与最稀格可能并列，`max_cell` /
`min_cell` 给的是第一个命中的位置，不代表唯一。

## 「有空格」说明什么

不一定说明有地空着。格子越小、株数越少，随机撒点也会留空。

所以 `grid` 同时给 `empty_if_random`（该粒度下随机分布的期望空格数
= n²·e^(-平均每格株数)），用来对照。实测 6×6：15/30 张出现空格，
但实测空格只有 0~3 个，随机期望是 6~9 个——**空格比随机还少**，
把它读成缺苗或空地是反的。

`empty_cells` 少于 `empty_if_random` 时，正确说法是"空格没有多到随机水平"。
`mean_per_cell < 1.5` 时不给 `pattern` 判断：格子数远多于株数时
抽样波动比信号大，报"规则"或"聚集"都是噪声。

## 不能说什么

- **不能说田间均匀。** 图像是一块田的裁片，图内均匀跟整块地均匀是两件事。
  正确说法是"相对本图"。
- **不能说缺苗率。** 需要地面标定的理论株距，本数据集没有。
- **不能给株距/行距。** 需要 GSD（每像素对应多少厘米），同样没有标定。
  像素级的框间距只能说明"图上相隔多少像素"，换个航高就变了。
- **不能描述 4×4 之外的方位细节。** "左侧中部两株"这类说法在 `grid` 里
  没有对应字段；要说得引用具体格坐标，如"第 2 行第 1 列 2 株"。
