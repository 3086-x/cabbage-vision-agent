# 密度分级

## 阈值从哪来

分级阈值来自检测仓库训练集的逐图标注框数分布（262 张图）：

    min=31  Q1=45  中位=49  Q3=53  max=83

`config.DENSITY_QUARTILES = (45, 53, 65)` 对应：

| 等级 | 区间 |
|---|---|
| `sparse` | count < 45 |
| `moderate` | 45 ≤ count < 53 |
| `dense` | 53 ≤ count < 65 |
| `very_dense` | count ≥ 65 |

前两个数是实测 Q1 与 Q3；**65 不是四分位点**，而是为离群密集图留的外推边界。
把它当成 Q4 或「第三四分位」是错的。

## 为什么只说「相对密度」

这些图来自同一块田、同一航高，株数天然集中在 45~55。绝对阈值几乎不产生区分度，
所以 `sparse/moderate/dense` 只有**相对本数据集**的意义，不能当农学密度结论。

有个反直觉的数据点：完整大田图 `img_1.jpg` 检出 65~67 株，按阈值被判为 `very_dense`；
而它只是同一块田的普通视角。这说明阈值是数据分布的函数，不是长势的函数。

## 更好的跨图比较量

`mean_density_per_mpx`（株/百万像素）不依赖分级阈值，适合横向比较不同分辨率/航高的图。
它仍然不能换算成株/亩。

## 能不能换算成株/亩

不能。换算需要地面标定（GSD，每像素对应多少厘米），本数据集没有。
任何「每亩多少株」的回答都缺少标定依据，属于越界结论；评测里把这类回答判为失败。
